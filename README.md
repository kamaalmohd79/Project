# Alex Johnson | Digital Portfolio

A realistic, responsive sample portfolio website made with plain HTML and CSS. This project is intended as demo content for learning how to publish a website with GitHub Pages.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `my-first-website` (or another name you prefer).
2. Upload all files and folders in this project. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The project URL usually looks like:

   `https://YOUR-USERNAME.github.io/my-first-website/`

Replace `YOUR-USERNAME` with your GitHub username.

## Project files

- `index.html` — website content and layout
- `styles.css` — responsive styling
- `assets/favicon.svg` — simple site icon

## Demo content note

Alex Johnson, the projects, and the contact email are fictional placeholders. Replace them with your own content before using this as a real portfolio.

The website uses Google Fonts when internet access is available and includes CSS fallbacks.
